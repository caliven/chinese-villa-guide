## 修改与构建

使用支持Vite 8的Node.js版本（推荐Node 24）。

```sh
cd villa-3d-src
npm ci
npm run check
npm run build
```

`npm run check` 包含 TypeScript 检查和 `node:test`；`npm run build` 包含 TypeScript 检查和 Vite 构建。**本次红线梯田任务用户明确要求跳过验证**，可在依赖已安装的源码目录仅执行 `./node_modules/.bin/vite build` 更新静态产物，不额外运行检查或浏览器验收。正常任务仍按改动范围选择验证；不要把历史结果当作本次结果。

构建仅输出到兄弟目录 `villa-3d/`。`npm run dev` 可单独开发查看器；验证“返回建房指南”和旧日照页面时，请使用仓库根目录的静态服务。GitHub Pages使用相对资源路径，无外部字体、地图或模型接口依赖。

## 必须保留的未决项

1. **车辆通行尚未通过校核。** 用户提供入口预估2.5米净宽、邻居平台拟切开为露天口的意向；实际切口范围与协商结果仍待确认。道路位置已校正到面对房子时邻居木房的左侧。场地视图前地坪完整，地库视图用投影提示保留地坪、用虚线标拟切口；接入仍经过保留地坪下方，净高待测。模型5×2.5米切口形状不是协商结果。L9长5.218米、车身宽1.998米、高1.8米、轴距3.105米；车宽不含镜。第二辆星愿只作外观，不参与L9占位检查。当前空间探索曲线已补整车平面扫掠和模型柱墙投影潜在冲突筛查，但不是按转弯半径生成的轨迹；后视镜、坡道纵向扫掠、实际净高、驶出或第二辆独立进出仍未完成校核。
2. **标高与结构待测。** 道路初值沿用 `surroundings.road.entryY` 的连续纵坡示意值，坡长初值5米；两者都待测、可探索调整。院坪结构暂占0.45米，地库地面-2.95米，从而表达梁下2.5米净高目标；不能由此认定开挖深度或结构梁高可行。邻居梁底1.8米/板底2米没有用于推算道路标高。
3. **双桌满座通道偏紧。** 36㎡辅楼（默认进深 8 m）摆入直径2米的12座圆桌及6座小桌，实体座椅在墙内；完全拉椅时圆桌东侧只余约0.31米，两桌包络局部相交。页面直接显示这一问题，不将“摆得下”当作“同时满座通行合格”。仍需在10/12人、桌径、座椅形式及辅楼功能分配之间深化。
4. **日照是模型比较。** SunCalc 2.x使用北起顺时针的角度，统一北京时间。窗外3点每半小时射线采样表示直射遮挡，不能折算为室内照度或法定日照时数。树叶透明贴图在射线中按叶簇面片概括，近似树形、地形和邻房均影响结果。
5. **不是施工图。** 梁柱、砖混承重体系、挑空开口、楼梯细部、地库承托、邻居平台切割、挡土排水与柴火烟道需结合现场完成专业设计。模型不认定土地界址或审批范围。
