# 安化 · 山居 — 实景别墅方案

按已确认的主楼135㎡、辅楼45㎡方案制作的交互式概念模型。使用现有航拍照片与已知尺寸重建场地关系，可以查看外观、分层户型、地库空间与日照遮挡。周边为人工校准的近似模型，不是航测生成的实景网格。

**接手先读 [HANDOFF.md](HANDOFF.md)。最新红线梯田修正尚未实现。** 当前源码仍包含过于平直的田坎、辅楼右侧梯田位置偏后的问题，以及将旁边未开挖田面直接绑定地库地坪的旧假设。用户提供的 [红线原图](references/terrace-contours-2026-10-13.png) 已保存在仓库；最新要求、标高区别和修改入口见交接记录。

## 打开

直接运行仓库根目录的 `启动服务.command`（macOS）或 `启动服务.bat`（Windows），在文档中心选择“实景别墅3D方案”。也可以在仓库根目录运行：

```sh
python3 -m http.server 8000
```

打开 `http://localhost:8000/villa-3d/`。构建后的页面已经包含在 `villa-3d/`，家人查看不需要安装Node。请通过HTTP服务打开，不要直接双击HTML文件。

## 修改与构建

使用支持Vite 8的Node.js版本（推荐Node 24）。

```sh
cd villa-3d-src
npm ci
npm run check
npm run build
```

`npm run check` 包含 TypeScript 检查和 `node:test`；`npm run build` 包含 TypeScript 检查和 Vite 构建。**本次红线梯田任务用户明确要求跳过验证**，可在依赖已安装的源码目录仅执行 `./node_modules/.bin/vite build` 更新静态产物，不额外运行检查或浏览器验收。正常任务仍按改动范围选择验证；不要把历史结果当作本次结果。

构建仅输出到兄弟目录 `villa-3d/`。`npm run dev` 可单独开发查看器；验证“返回建房指南”和旧日照页面时，请使用仓库根目录的静态服务。GitHub Pages使用相对资源路径，无外部字体、地图或模型接口依赖。

`sunlight-3d/` 是原有模拟器的构建产物，本次没有修改。不要编辑其中的压缩文件。

## 查看功能

- 场地模型：新建/现状、鸟瞰/北立面/南侧/院坪/地库、隐藏新房屋顶、尺寸与主楼前伸重叠范围、实拍对照、图片导出。
- 分层户型：三层平面图、房间说明、真实门窗的立体剖看、分层展示。平面与3D共用房间、墙段、门窗及家具数据。
- 日照分析：四季日期、北京时间、太阳高度与方位；相同时间比较无连续后阳台与三楼局部1.2米浅阳台；按半小时显示南窗3点直射光采样。
- 地库：展示自家异形边界下的车位、柱位、邻居拟露天切口；院坪中央楼梯已取消；可以调整假定道路标高与坡长、沿示意路线移动L9。
- 资料与校核：用户提供、照片估算、设计建议、待测四类证据，参考照片、待测筛选与参数JSON下载。

## 坐标与设计约束

全部以米为单位。X向东、Y向上、Z向南，旧房前坪外缘Z=0，新院坪暂定Y=0。平面图北朝上、东朝右；从北向南看正立面时，东侧主楼位于画面左侧。

21.1米宽按 `0.8 + 4.5 + 1.5 + 13.5 + 0.8` 分配。主辅楼北墙Z=-1、南墙Z=9，后边界Z=10.8，前伸原旱地1米。135㎡+45㎡表示主辅楼主体首层控制轮廓。用户确认外伸门厅另计：本版门厅4.8×2米，新增投影9.6㎡，几何投影合计189.6㎡；不是户内净面积、三层总建筑面积或报建面积结论。

三楼只向北退1.8米；楼面标高0/3.6/7.2米、檐口10.5米，两翼屋脊起高1.45米、中央官帽檐基11.8米和起高1.35米为参照效果图的造型参数。客厅上方二层没有楼板，门厅柱间二层没有平台，三楼有平台。卧室按2/3/2设置，老人房东南侧设独卫。主楼没有厨房。

前田8.6/5/3米来自用户，3米测点的横向位置及中间折点来自照片估算。用户补充确认右端仍约3米、不收尖；本版以3.1米表达栏杆占用后约2米前通道，并接入辅楼右侧0.8米墙至界过道和后段同高梯田。侧道净宽需另扣栏杆，边界折点仍需现场校准。周边邻房、树木、道路与远山高度不能视为实测值。

## 场地关系校准（2026-10-13）

本节记录红线要求之前已实现的基准，并不表示最新梯田曲线已还原。

按用户面对房子时的左右方向及 `dji_fly_20260816_131730_732_1786857561396_photo.jpg` 修正：邻居院坪覆盖其整个面宽，道路紧邻邻居木房左墙外；前后邻房左边与该木房左边对齐。后方木房右边到主楼中部，放到第二层梯田；前方砖房为两层，右边到主楼从画面左侧起约1/3处。

两侧移除树木与随机灌木，右侧为连续梯田，左侧道路外为向前伸出的高地。树木仅位于后方木房背后的山上。**待修正的旧实现：**辅楼右侧田坎按从前墙向后约2/3处定位，后段与院坪齐平、前段与示意地库地坪齐平。用户最新说明要求右侧梯田更向前伸出、田埂与地库外沿连续，且旁田未开挖、只有地库局部下挖；不能继续把旁田强制设为 `garageFloor`。具体原田面标高与开挖差仍待测。

地库前方第一层田比地库地坪低约2米，前方砖房所在台地再低约1.5米；按地库示意标高−2.95米，分别绘为−4.95和−6.45米。原旱地−2米只用于现状，不能混用。院坪正前电杆和架空线按拆除计划移除。

对齐和上下层关系来自用户；左侧高地+0.6米、后方第二田+5米、前方砖房每层3.2米、道路纵坡和田坎折点为本版照片估算，不能视为新增实测。道路使用连续、不重复的三角面，周边地形不再穿过路面。

## 外观调整（2026-10-13）

参照 `新中式参考图/新中式效果图1.jpeg` 制作外伸2米通高门厅、三楼平台、玻璃栏板、层叠石材檐口、凹槽立柱、回纹装饰和中央抬高官帽。二楼顶部正面飘檐70厘米；三楼屋顶前、左、右各80厘米。四坡五脊瓦口收于环形天沟内，天沟槽底、外挡边与墙边落水管均有几何表达。三楼側檐恰到暂定地界，管道内收。单张透视参考不能提供全部构件尺寸，屋顶背面和细部不是测绘复刻。

门厅平台及投影同步到分层平面和3D；柱间3.6米标高不加平台。院坪中间楼梯、洞口和围栏删除，地库步行出入口待后续布置。

## 必须保留的未决项

1. **车辆通行尚未通过校核。** 用户确认入口预估2.5米净宽、邻居平台切开为露天口。道路位置已校正到面对房子时邻居木房的左侧。场地视图前地坪完整，仅地库视图揭示拟切口；车辆接入需经过保留地坪下方，这一段净高仍未通过校核。模型5×2.5米切口形状不是协商结果。L9长5.218米、车身宽1.998米、高1.8米、轴距3.105米；车宽不含镜。当前路线是空间探索曲线，不是按转弯半径生成的轨迹；占位检查不覆盖柱墙碰撞、后视镜、坡道纵向扫掠、驶出或第二辆车独立进出。
2. **标高与结构待测。** 道路初值-2米、坡长5米均为可调整示意。院坪结构暂占0.45米，地库地面-2.95米，从而表达梁下2.5米净高目标；不能由此认定开挖深度或结构梁高可行。邻居梁底1.8米/板底2米没有用于推算道路标高。
3. **双桌满座通道偏紧。** 45㎡辅楼摆入直径2米的12座圆桌及6座小桌，实体座椅在墙内；完全拉椅时圆桌东侧只余约0.31米，两桌包络局部相交。页面直接显示这一问题，不将“摆得下”当作“同时满座通行合格”。仍需在10/12人、桌径、座椅形式及辅楼功能分配之间深化。
4. **日照是模型比较。** SunCalc 2.x使用北起顺时针的角度，统一北京时间。窗外3点每半小时射线采样表示直射遮挡，不能折算为室内照度或法定日照时数。树叶透明贴图在射线中按叶簇面片概括，近似树形、地形和邻房均影响结果。
5. **不是施工图。** 梁柱、砖混承重体系、挑空开口、楼梯细部、地库承托、邻居平台切割、挡土排水与柴火烟道需结合现场完成专业设计。模型不认定土地界址或审批范围。

## 源码位置

- `src/data.ts`：统一尺寸、房间、隔墙、家具、证据状态。
- `src/facades.ts`：平面和立体共用的外墙与门窗。
- `src/architecture.ts`、`src/facade-details.ts`、`src/primitives.ts`：建筑、官帽、天沟、石材线脚、曲面灰瓦屋顶、楼梯与车辆。
- `src/terrain.ts`：邻房、现状、前院及地库。
- `src/surroundings.ts`、`src/site-ground.ts`：周边对齐关系、梯田高差、后山林木及无重叠路面。
- `src/viewer.ts`：镜头、交互、可见性、太阳与示意车辆路线。
- `src/plan.ts`：户型图与拉椅空间。
- `src/main.ts`、`src/style.css`：中文界面与移动端布局。
- `tests/layout.test.ts`：面积、房间数量、门洞、通达性、屋檐边界、门厅挑空、座椅和太阳方向检查。
- `tests/site.test.ts`：道路/坡道共面与接续、周边房屋关系、田面高差、院坪通道和后山植被检查；其中右侧下田同高的旧断言需随最新事实更新，本次不运行。
- `HANDOFF.md`、`references/`：接续任务、来源图、当前实现与最新要求的差异。当前红线图为原样保留，不经过 `public/` 发布或修改原始照片。

照片优化副本位于 `public/photos/`，原始航拍和造型参考图片未改动。
