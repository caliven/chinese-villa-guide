# 安化 · 山居 — 实景别墅方案

按已确认的主楼135㎡、辅楼45㎡方案制作的交互式概念模型。使用现有航拍照片与已知尺寸重建场地关系，可以查看外观、分层户型、地库空间与日照遮挡。周边为人工校准的近似模型，不是航测生成的实景网格。

**接手先读 [HANDOFF.md](HANDOFF.md)。红线梯田修正已写入源码，效果待用户查看。** 田埂按 [红线原图](references/terrace-contours-2026-10-13.png) 的相邻关系与凹凸走势近似描绘；旁田向前展开，与地库共享外沿，未挖原田面和地库完成面分开。此次只生成静态产物，未运行测试、类型检查或浏览器验证。

## 打开

直接运行仓库根目录的 `启动服务.command`（macOS）或 `启动服务.bat`（Windows），在文档中心选择“实景别墅3D方案”。也可以在仓库根目录运行：

```sh
python3 -m http.server 8000
```

打开 `http://localhost:8000/villa-3d/`。构建后的页面已经包含在 `villa-3d/`，家人查看不需要安装Node。请通过HTTP服务打开，不要直接双击HTML文件。

## 修改与构建

使用支持Vite 8的Node.js版本（推荐Node 24）。

```sh
cd villa-3d-src
npm ci
npm run check
npm run build
```

`npm run check` 包含 TypeScript 检查和 `node:test`；`npm run build` 包含 TypeScript 检查和 Vite 构建。**本次红线梯田任务用户明确要求跳过验证**，可在依赖已安装的源码目录仅执行 `./node_modules/.bin/vite build` 更新静态产物，不额外运行检查或浏览器验收。正常任务仍按改动范围选择验证；不要把历史结果当作本次结果。

构建仅输出到兄弟目录 `villa-3d/`。`npm run dev` 可单独开发查看器；验证“返回建房指南”和旧日照页面时，请使用仓库根目录的静态服务。GitHub Pages使用相对资源路径，无外部字体、地图或模型接口依赖。

`sunlight-3d/` 是原有模拟器的构建产物，本次没有修改。不要编辑其中的压缩文件。

## 坐标与设计约束

全部以米为单位。X向东、Y向上、Z向南，旧房前坪外缘Z=0，新院坪暂定Y=0。平面图北朝上、东朝右；从北向南看正立面时，东侧主楼位于画面左侧。

21.1米宽按 `0.8 + 4.5 + 1.5 + 13.5 + 0.8` 分配。主辅楼北墙Z=-1、南墙Z=9，后边界Z=10.8，前伸原旱地1米。135㎡+45㎡表示主辅楼主体首层控制轮廓。用户确认外伸门厅另计：本版门厅4.8×2米，新增投影9.6㎡，几何投影合计189.6㎡；不是户内净面积、三层总建筑面积或报建面积结论。

三楼只向北退1.8米；楼面标高0/3.6/7.2米、檐口10.5米、屋脊起高1.45米。中央官帽是正屋檐下的中部额枋，不再另起高于正屋的帽顶。一、二层中间墙与两侧齐平，门厅柱仍外伸2米，柱间二楼没有平台，三楼有平台。卧室按2/3/2设置，老人房东南侧设独卫。主楼没有厨房。辅楼屋顶用与主楼相同的环形天沟。

院坪外沿是向外鼓的圆弧：西端仍约3.1米、不收尖，辅楼前留约2米通道；东端8.6米改从主楼前墙往外量。中段比两端连线更远离房子，鼓出量是俯视图修正，不是新的实测。旁边木屋前的田与两侧院坪同一标高接通。前方邻居砖房已往道路反方向退了0.6米，屋后田宽按5/2收到约0.4米，田埂外沿仍在原来大约1米的位置。侧道净宽需另扣栏杆，边界折点仍需现场校准。周边邻房、树木、道路与远山高度不能视为实测值。

## 场地关系校准（2026-10-13）

本节包含最新红线曲线调整。控制点是结合已知尺寸与斜向航拍的人工近似，不是正射测绘坐标；本轮未验证画面效果。

按用户面对房子时的左右方向及 `dji_fly_20260816_131730_732_1786857561396_photo.jpg` 修正：道路紧邻邻居木房左墙外；前后邻房左边与该木房左边对齐。后方木房右边到主楼中部，放到第二层梯田；前方砖房右边到主楼从画面左侧起约1/3处。邻居木屋前面整段已与两侧院坪拉平接通。前方矮楼与两层楼的交接仍对齐堂屋中线以西约0.5米。左侧一层与主楼一层齐平，离开马路约0.8米，北面不砌墙。红顶仍架空，西侧高点大约低于主体屋脊1.8米，东檐比一层东墙再挑出约0.4米。0.5米、0.8米、0.4米和1.8米都是口述大约值，不是新的测绘。

两侧仍不种树，树木仅位于后方木房背后的山上。辅楼右侧田埂、前方低田、道路外高地和屋后各级田埂现使用各自的弯曲控制点，带有外凸、内收和宽窄变化。按浏览器标记，右侧上田靠墙的落差位置从原约2/3进深处向房前伸出：先约1米，2026-10-14再加1.5米。下方旁田近屋的一整段与地库右端外沿同线，没有前后错位；近屋下田因此比上田窄。此段暂按 X=-8 到0、Z=-3.1 建模，8米是示意范围而非实测。俯瞰航拍里西侧远离房子的田埂朝南弯，东侧高地只缓缓北偏，不再把西侧远端朝北甩。院坪、栏杆、地库底板及外墙仍随同一外沿生成。栏杆柱按弧长布置，避免曲线采样越密柱子越拥挤。

旁田使用独立的 `adjacentUnexcavatedLevel`，暂为−2米；地库完成面仍为−2.95米，以边界处的局部开挖立面表达差异。0.95米高差只是示意，不能视为新增实测。后田和山脚也以曲线衔接，田面、作物、立面及 `groundHeight()` 同步；道路区保持不铺重叠田面。

地库前方第一层田比地库地坪低约2米，前方砖房所在台地再低约1.5米；按地库示意标高−2.95米，分别绘为−4.95和−6.45米。`originalField=-2` 用于现状；旁田同为−2米的初值是另一个独立待测参数，不能与地库完成面混用。院坪正前电杆和架空线按拆除计划移除。

对齐和上下层关系来自用户；东侧大平地与屋后第一层梯田同一标高，沿用屋后田+2.5米。马路连续上坡到这一层后停止，屋后木房左侧不再留路。后方第二田+5米、道路纵坡和田坎折点为本版照片估算，不能视为新增实测。前方砖房右侧主体仍是两层人字坡，屋脊约高于自家一层顶2米；按航拍把坡改平，起坡约0.9米。进深向北加到约9.5米，后墙和屋后田外沿不动。主体北立面是三开间，中间堂屋、两侧卧室。分界对照照片，不是实测。左侧邻居木房和屋后木房也改为人字坡，仍用原来的深色瓦和木山墙。旁边木房按一明两暗分三开间，中间堂屋更宽，前墙与自家旧木房前墙对齐，进深约8.8米，比自家旧木房大约深0.9米，多出的长度在后墙，面宽仍约12米；屋后木房为八开间，面对房子时左侧第三间是稍宽的堂屋。层高未改。8.8米和前墙对齐是口述，不是测绘。现状视图里的自家旧木房同样是人字坡和三开间，堂屋稍宽，檐口比左侧邻居木房低约30厘米；旧白砖房平顶在前、后、右侧加了栏杆。开间尺寸是总宽内的划分，不是逐间实测。道路使用连续、不重复的三角面，周边地形不再穿过路面。

## 外观调整（2026-10-13）

参照新中式效果图制作外伸2米通高门厅、三楼平台、玻璃栏板、层叠石材檐口、凹槽立柱和回纹。官帽造型改按效果图2：中部额枋留在正屋檐下，帽顶不再高出正屋屋脊。二楼顶部正面飘檐70厘米；三楼屋顶前、左、右各80厘米。主楼与辅楼的四坡瓦口都收于环形天沟内，含槽底、外挡边和墙边落水管。三楼侧檐恰到暂定地界，管道内收。单张透视参考不能提供全部构件尺寸，屋顶背面和细部不是测绘复刻。

门厅平台及投影同步到分层平面和3D；柱间3.6米标高不加平台。院坪中间楼梯、洞口和围栏删除，地库步行出入口待后续布置。

## 必须保留的未决项

1. **车辆通行尚未通过校核。** 用户确认入口预估2.5米净宽、邻居平台切开为露天口。道路位置已校正到面对房子时邻居木房的左侧。场地视图前地坪完整，仅地库视图揭示拟切口；车辆接入需经过保留地坪下方，这一段净高仍未通过校核。模型5×2.5米切口形状不是协商结果。L9长5.218米、车身宽1.998米、高1.8米、轴距3.105米；车宽不含镜。当前路线是空间探索曲线，不是按转弯半径生成的轨迹；占位检查不覆盖柱墙碰撞、后视镜、坡道纵向扫掠、驶出或第二辆车独立进出。
2. **标高与结构待测。** 道路初值-2米、坡长5米均为可调整示意。院坪结构暂占0.45米，地库地面-2.95米，从而表达梁下2.5米净高目标；不能由此认定开挖深度或结构梁高可行。邻居梁底1.8米/板底2米没有用于推算道路标高。
3. **双桌满座通道偏紧。** 45㎡辅楼摆入直径2米的12座圆桌及6座小桌，实体座椅在墙内；完全拉椅时圆桌东侧只余约0.31米，两桌包络局部相交。页面直接显示这一问题，不将“摆得下”当作“同时满座通行合格”。仍需在10/12人、桌径、座椅形式及辅楼功能分配之间深化。
4. **日照是模型比较。** SunCalc 2.x使用北起顺时针的角度，统一北京时间。窗外3点每半小时射线采样表示直射遮挡，不能折算为室内照度或法定日照时数。树叶透明贴图在射线中按叶簇面片概括，近似树形、地形和邻房均影响结果。
5. **不是施工图。** 梁柱、砖混承重体系、挑空开口、楼梯细部、地库承托、邻居平台切割、挡土排水与柴火烟道需结合现场完成专业设计。模型不认定土地界址或审批范围。
