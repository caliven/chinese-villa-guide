## 必须保留的未决项

1. **车辆通行尚未通过校核。** 用户确认入口预估2.5米净宽、邻居平台切开为露天口。道路位置已校正到面对房子时邻居木房的左侧。场地视图前地坪完整，仅地库视图揭示拟切口；车辆接入需经过保留地坪下方，这一段净高仍未通过校核。模型5×2.5米切口形状不是协商结果。L9长5.218米、车身宽1.998米、高1.8米、轴距3.105米；车宽不含镜。地库停放的第二辆按2025款吉利星愿做成银色外观，尺寸用厂商公开数据，不参与这辆L9的占位检查。当前路线是空间探索曲线，不是按转弯半径生成的轨迹；占位检查不覆盖柱墙碰撞、后视镜、坡道纵向扫掠、驶出或第二辆车独立进出。
2. **标高与结构待测。** 道路初值-2米、坡长5米均为可调整示意。院坪结构暂占0.45米，地库地面-2.95米，从而表达梁下2.5米净高目标；不能由此认定开挖深度或结构梁高可行。邻居梁底1.8米/板底2米没有用于推算道路标高。
3. **双桌满座通道偏紧。** 45㎡辅楼摆入直径2米的12座圆桌及6座小桌，实体座椅在墙内；完全拉椅时圆桌东侧只余约0.31米，两桌包络局部相交。页面直接显示这一问题，不将“摆得下”当作“同时满座通行合格”。仍需在10/12人、桌径、座椅形式及辅楼功能分配之间深化。
4. **日照是模型比较。** SunCalc 2.x使用北起顺时针的角度，统一北京时间。窗外3点每半小时射线采样表示直射遮挡，不能折算为室内照度或法定日照时数。树叶透明贴图在射线中按叶簇面片概括，近似树形、地形和邻房均影响结果。
5. **不是施工图。** 梁柱、砖混承重体系、挑空开口、楼梯细部、地库承托、邻居平台切割、挡土排水与柴火烟道需结合现场完成专业设计。模型不认定土地界址或审批范围。
